# Frontline 3D

A browser-based 3D arcade FPS prototype built with Three.js.

## Run it
1. Download and unzip the project.
2. Open the folder in VS Code.
3. Start a local server (recommended: the **Live Server** extension), then open `index.html`.
   - You can also run `python3 -m http.server 8000` in the project folder and visit `http://localhost:8000`.
4. Internet access is required to load Three.js from jsDelivr.

## Controls
- WASD: move
- Mouse: look around
- Left click: fire
- Shift: sprint
- Esc: release mouse; click the game to recapture it

## Included
- Four selectable, fictionalized historical-theatre-inspired arenas
- Assault, Machine Gunner, Recon, and Support class presets
- Basic 3D opponents, scoring, health HUD, lighting, shadows, fog, and map scenery

## Notes
This is a playable starter prototype, not a finished multiplayer game. Maps and equipment are stylized and fictionalized; weapon behavior is arcade-only rather than a real-world weapon simulation. All combat is non-graphic.
